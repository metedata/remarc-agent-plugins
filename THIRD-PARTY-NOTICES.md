# Third-party notices

The canonical distribution notice for third-party runtime code bundled in
`plugins/remarc/mcp/dist/index.js` is
[`plugins/remarc/THIRD-PARTY-NOTICES.md`](plugins/remarc/THIRD-PARTY-NOTICES.md).
That notice is shipped inside every installed or cached `remarc` core plugin
package, alongside the package-local `LICENSE`.

The bundles distributed by `plugins/remarc-hooks` and `plugins/remarc-wake`
contain Remarc project code and Node.js built-in imports only. They do not
bundle third-party runtime code. Each independently distributed package still
ships its own copy of the Remarc MIT `LICENSE`.
